# Glance
한눈에 훑어보다'라는 뜻으로, 무거운 로딩 없이 앱을 켜자마자 빠르게 뉴스를 파악하는 프로젝트

## 프로젝트 기획서

### 1. 프로젝트 개요
- 프로젝트명: Project Glance (가칭)
- 목적: 매일 쏟아지는 한국의 주요 뉴스(IT/기술, 경제, 사회)를 한눈에 파악할 수 있는 고성능 웹 대시보드 구축
- 배포 환경: GitHub Pages(정적 웹 호스팅)
- 핵심 방식: 별도의 백엔드 서버 없이 클라이언트(브라우저)에서 외부 API를 직접 호출하여 구조화된 데일리 브리핑 제공

### 2. 기술 스택 및 아키텍처
- 코어 라이브러리: Preact
  - 가벼운 용량과 빠른 렌더링 성능을 통해 빠른 인터페이스 반응성을 구현
- 스타일링: Pure CSS 또는 CSS Modules
  - 별도의 프레임워크 없이 순수 CSS를 활용해 컴포넌트 단위 스타일링 적용
- 데이터 통신: Fetch API
  - 브라우저 내장 API를 사용해 외부 뉴스 데이터를 비동기적으로 호출
- 상태 관리: Preact Hooks(useState, useEffect)
  - 카테고리 전환, 로딩 상태, 에러 상태를 관리
- 로컬 저장소: LocalStorage
  - 다크 모드 설정과 마지막으로 본 카테고리를 저장해 재접속 시 유지

### 3. 주요 기능 정의
- 카테고리별 실시간 브리핑
  - IT/기술, 경제, 사회 등 주요 섹션별 탭을 제공하고 최신 기사 목록을 그리드 형태로 표시
- 비동기 데이터 로딩 UI
  - API 통신 중 로딩 스피너 또는 스켈레톤 UI를 제공해 사용자 경험을 향상
- 에러 핸들링 및 CORS 대응
  - API 호출 실패 또는 브라우저 보안 정책(CORS) 차단 시 안내 문구를 출력하고 화면이 멈추지 않도록 처리
- 개인화 환경 설정
  - 다크 모드 전환 기능을 제공하고 선택값을 브라우저에 저장해 재접속 시 유지
- 반응형 레이아웃
  - 모바일, 태블릿, 데스크톱 환경에 맞춰 뉴스 카드 배치를 유동적으로 조정

### 4. 화면 레이아웃 구조
- Header
  - 로고, 타이틀, 다크 모드 토글 버튼
- Navigation
  - 카테고리 탭(기술, 경제, 사회 등)
- Main Board
  - 뉴스 카드 그리드 뷰, 기사 제목/요약/출처/링크 표시
- Footer
  - API 출처 표기, 저작권 정보 등 안내 문구 표시

### 5. 구현 방향
- 정적 웹 애플리케이션으로 빠르게 개발하고 GitHub Pages에 배포
- 브라우저 단에서의 렌더링 성능과 깔끔한 구조화에 초점을 둠
- 사용자가 짧은 시간 안에 핵심 정보를 파악할 수 있도록 정보 밀도를 적절히 조절

### 6. MVP 범위
1. 카테고리별 뉴스 탭 전환
2. 뉴스 카드 그리드 렌더링
3. 로딩/에러 상태 UI
4. 다크 모드 토글
5. 반응형 레이아웃 적용
6. GitHub Pages 배포

### 7. 향후 확장 아이디어
- 검색 기능 추가
- 북마크 저장 기능
- 관심 분야 맞춤형 뉴스 필터링
- 실시간 알림 또는 주간 요약 기능
